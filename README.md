# AI فقط Chatbot نیست! — AI Club / Quera

## بازچینی فعلی: سه اکوسیستم و تیم‌های کوئرا

مسیر فعلی در `ecosystems.js` تعریف شده: Claude و Claude Code، GPT/ChatGPT و Codex، Gemini و Antigravity. برای هر اکوسیستم قابلیت‌های داخل اپ، روش شروع و مثال‌های کاری معرفی می‌شوند. ابزارهای دیگر فقط یک اسلاید معرفی کوتاه و بخش مرجع دارند.

مثال‌ها سناریوهای پیشنهادی‌اند: سگمنت‌بندی پیام و قیف کمپین **کالج**، تولید محتوای سوشال و فرم مشاوره **بوت‌کمپ**، آماده‌سازی فروش و پنل لید **تلنت**. هیچ داده واقعی داخلی یا نتیجه اجرای واقعی در ارائه ادعا نشده است. مخاطبان: مارکتینگ، سوشال، فروش، محصول و فنی.

همه اسلایدها انیمیشن ورود مرحله‌ای و حرکت آرام نور پس‌زمینه دارند. هنگام نمای کلی انیمیشن محتوا متوقف می‌شود؛ `prefers-reduced-motion` رعایت می‌شود.

منابع معرفی قابلیت‌ها: [Claude](https://claude.com/product/overview)، [Claude Code](https://code.claude.com/docs/en/overview)، [ChatGPT](https://help.openai.com/en/articles/9260256-chatgpt-capabilities-overview)، [Codex](https://developers.openai.com/codex/)، [Gemini Deep Research](https://support.google.com/gemini/answer/15719111). روش دسترسی و جزئیات قابلیت‌ها تابع حساب و تنظیمات محصول است.

نسخه فعلی ۲۹ اسلاید دارد و محور آن **از پاسخ گرفتن به واگذاری کار به Agent** است. ترتیب: عنوان → تفاوت Chatbot و Agent، چرخه اجرا و انواع Agent → دو اسلاید معرفی تصویری ابزارهای اصلی → شرح کار → مسیرها و مراحل اتصال ابزار و تفاوت محیط‌ها → محصولات و جزئیات ابزارها → نمایش آموزشی آفلاین → هفت مثال تصویری روزمره و کاری → مرجع → اقدام بعد از جلسه. اسلایدهای تکراری انتخاب ابزار، شروع، هدایت و گردش کار ادغام یا حذف شده‌اند. بخش ثبت تجربه (اسلاید ۲۷ نسخه قدیمی) حذف شده است. نمای کلی از بالا سمت راست شروع می‌شود و هر ردیف راست‌به‌چپ است. شمارنده از آرایه اسلایدها محاسبه می‌شود. فهرست تفصیلی پایین، ساختار نسخه قبلی را ثبت می‌کند.

فایل `integrations.js` ترتیب نهایی و مثال‌های تصویری را تنظیم می‌کند: سفر، ایمیل و تقویم، مرتب‌کردن فایل‌ها، خرید و مقایسه، گزارش Sheets، بسته محتوا و نمونه صفحه. هر مثال ورودی، مسیر اتصال، اقدام Agent و خروجی مشخص دارد. تصاویر، نمای ابزار مربوط‌اند و نتیجه اجرای زنده این سناریوها نیستند. اتصال داخلی، MCP، API و CSV مسیرهای جدا هستند؛ خواندن و نوشتن Sheets به ابزار و دسترسی محیط وابسته است. ارائه هیچ اتصال زنده یا API اجرا نمی‌کند.

فایل `refinements.js` معرفی ابزارها از اسلاید ۱۲ به بعد را بازنویسی می‌کند و به مثال‌ها پیش‌نمایش ساختار خروجی می‌دهد. همه ۱۱ اسلاید ابتدایی عکس، اسکرین‌شات یا نمودار دارند؛ نمودارهای اختصاصی چرخه Agent، اتصال ابزار و شرح کار در `assets/` ذخیره شده‌اند. اسلاید آخر تشکر و دعوت به گفت‌وگو درباره تجربه‌های AI و Agentic است و تکلیف تعیین نمی‌کند.

تصاویر و اسکرین‌شات‌ها در `assets/screenshots/` به‌صورت محلی ذخیره شده‌اند و با کلیک بزرگ می‌شوند. منبع هر تصویر زیر آن آمده است؛ نمای آرشیوی، تصویر تبلیغاتی و اسکرین‌شات با عنوان مشخص معرفی می‌شوند. فایل `visuals.js` چیدمان تصاویر و المان‌های متحرک هر اسلاید را اضافه می‌کند. فایل `agents.js` ساختار نهایی Agentمحور را می‌سازد؛ مثال آفلاین چرخه ساخت صفحه محلی را توضیح می‌دهد و AI واقعی اجرا نمی‌کند.

ارائه داخلی برای همکاران: مرور قابلیت‌های موجود AI، ابزار مناسب هر نوع کار و نقطه شروع استفاده. تم سرمه‌ای و آبی با هویت بصری کوئرا، فونت محلی وزیرمتن و Canvas فضایی با دوربین Zoom/Pan.

## اجرا

`index.html` را مستقیم در یک مرورگر جدید باز کنید. نیازی به نصب، build، سرور، CDN، اینترنت یا اتصال API نیست. همه فایل‌ها و پوشه `assets` باید کنار هم بمانند.

ارائه برای Desktop و نمایش افقی طراحی شده است. در صفحه‌های کوچک، قاب کامل اسلاید متناسب با صفحه کوچک می‌شود. دکمه بالای صفحه، مرورگر را تمام‌صفحه می‌کند.

## کنترل‌ها

| کنترل | عملکرد |
| --- | --- |
| Arrow Left / Space | اسلاید بعد |
| Arrow Right | اسلاید قبل |
| Home / Esc | نمای کلی |
| End | آخرین اسلاید |
| Wheel | زوم حول نشانگر |
| Drag | جابه‌جایی Canvas |
| کلیک روی اسلاید در نمای کلی | ورود مستقیم به همان اسلاید |

در نمای کلی، هر اسلاید یک ناحیه انتخاب تمام‌قاب با شماره و عنوان دارد. کنترل‌های داخل اسلایدها غیرفعال‌اند؛ کلیک روی تصویر، متن یا محل دکمه‌ها هم فقط همان اسلاید را باز می‌کند. Pointer capture پس از شروع Drag واقعی فعال می‌شود تا کلیک عادی به Canvas منتقل نشود. کشیدن یک thumbnail موجب Pan می‌شود، نه انتخاب آن.

کلیدهای ناوبری هنگام تایپ در فرم غیرفعال‌اند. Esc در پنجره ابزار، پنجره را می‌بندد؛ Esc روی ارائه، نمای کلی را باز می‌کند. Space وقتی یک دکمه یا لینک فوکوس دارد، عملکرد همان کنترل را اجرا می‌کند.

محتوای اصلی در مسیر خطی و با Next/Previous قابل ارائه است. اسلاید سوم یک نمای خلاصه ثابت است؛ معرفی حوزه‌ها و ابزارها در اسلایدهای مستقل انجام می‌شود. اطلاعات لازم پشت کلیک روی دسته، تب یا پنجره پنهان نیست. تعامل‌های اختیاری شامل جزئیات ابزار، کپی نمونه درخواست، مرور مرحله‌های مثال، فیلتر Toolbox و ثبت یادداشت جلسه‌اند.

فرمت معرفی ابزار: **قابلیت → کاربرد کاری → روش شروع → مثال → لینک رسمی و نمونه درخواست قابل کپی**. سناریوی اصلی، انتخاب ابزار مستندسازی برای تیم و تهیه گزارش تصمیم است.

## تعامل‌های محلی

- دمو یک مثال آفلاین از ورودی و خروجی مورد انتظار است؛ هیچ جستجوی واقعی یا اجرای مدل انجام نمی‌شود.
- تصویر Codera، تصویر واقعی وب‌سایت رسمی است. Diagramهای Workflow و Coding، مسیر نمونه استفاده را نشان می‌دهند.
- فرم تجربه‌ها فقط در حافظه صفحه نگهداری می‌شود و با Refresh پاک می‌شود. ورودی‌ها با `textContent` یا HTML escaping نمایش داده می‌شوند.
- کپی نمونه درخواست ابتدا Clipboard API و سپس fallback محلی را امتحان می‌کند. در صورت نبود امکان کپی، متن برای انتخاب دستی نمایش داده می‌شود.
- فقط کلیک روی لینک رسمی یک ابزار، صفحه خارجی باز می‌کند.

## فایل‌ها و توسعه

```text
ai-club/
├── index.html
├── style.css
├── catalog.js       # ابزارها، کاربرد، روش شروع، نمونه درخواست و آیکن‌ها
├── content.js       # تعریف مستقل اسلایدها و قالب‌های محتوایی
├── script.js        # دوربین، ناوبری، انتخاب در نمای کلی و تعامل‌ها
├── assets/
│   ├── world-mark.svg
│   ├── quera-logo.svg
│   ├── codera-wordmark.svg
│   ├── codera-desktop.webp
│   └── fonts/
│       ├── Vazirmatn[wght].woff2
│       └── OFL.txt
└── README.md
```

برای افزودن اسلاید، یک تعریف با `id`، `title`، `kicker` و تابع `render` به آرایه `slides` در `content.js` اضافه کنید. چیدمان فضایی، نمای کلی و شمارنده از تعداد واقعی اسلایدها محاسبه می‌شوند. هر اسلاید یک `data-scene` با شناسه خودش دارد که برای استایل اختصاصی قابل استفاده است.

## فونت و منابع

- [Vazirmatn](https://github.com/rastikerdar/vazirmatn) با مجوز SIL Open Font License؛ مجوز در `assets/fonts/OFL.txt` همراه پروژه است.
- رنگ `#0099cc` و لوگو از [وب‌سایت رسمی کوئرا](https://quera.org/) گرفته شده‌اند؛ طراحی ارائه نسخه dark با الهام از هویت کوئراست.
- تصویر Codera از [صفحه رسمی محصول](https://quera.org/codera/) نگهداری شده است.
- معرفی OpenCode بر اساس [وب‌سایت رسمی](https://opencode.ai/)، و Antigravity بر اساس معرفی رسمی [Google Developers](https://developers.googleblog.com/build-with-google-antigravity-our-new-agentic-development-platform/) است.
- لینک رسمی هر ابزار در ارائه موجود است. اطلاعات، توصیف قابلیت‌هاست؛ قیمت، شماره نسخه مدل و دسترسی وابسته به پلن مبنای محتوا نیستند.
- آیکن‌های رنگی ابزارها نشان‌های نمایشی ارائه‌اند؛ لوگوی رسمی همه محصولات نیستند.

## بررسی اجرا

نسخه فعلی با `file://` در Chromium headless بررسی شد:

- **کلیک واقعی موس روی هر ۲۶ thumbnail** در نمای کلی، همان اسلاید را باز کرد؛ پنجره یا کنترل داخلی ناخواسته اجرا نشد.
- Drag از روی thumbnail موجب Pan شد؛ کلیک بعدی دوباره اسلاید را انتخاب کرد.
- بارگذاری فونت محلی، جزئیات و کپی نمونه درخواست، همه فیلترهای Toolbox، مراحل مثال، اجرای توالی Agent و فرم جلسه بررسی شدند.
- ورود متنی مانند HTML در فرم و مثال، به‌صورت متن نمایش داده شد.
- Arrow Keys، Home، End، Esc، Wheel و رفتار ناوبری هنگام تایپ بررسی شدند.
- محتوای ۲۶ اسلاید در اندازه‌های 1440×900، 1024×768، 390×844 و 844×390 از قاب داخلی بیرون نزد؛ دسته‌های شش‌ابزاری Toolbox هم جداگانه بررسی شدند.
- خطای JavaScript ثبت نشد؛ حرکت دوربین با `requestAnimationFrame` بومی مرورگر بررسی شد.
- Screenshotهای واقعی نمای کلی، مرور کاربردها، تحقیق، معرفی Antigravity و Workflow بازبینی شدند.

حالت `prefers-reduced-motion` رعایت می‌شود. برای اجرای headless روی محیط macOS، رندر نرم‌افزاری و پردازش مراحل compositor فعال شدند؛ کد برنامه برای تست جایگزین نشده است.
